## 안녕에서 시작된 HALO

**HALO**라는 이름은 우리가 매일 주고받는 말,  
‘안녕’에서 출발했습니다.

안녕은 단순한 인사가 아니라  
상대방의 편안함과 평온함을 바라는 마음을 담고 있습니다.

하지만 우리는 가장 가까운 사람인 부모님께  
그 안녕의 의미를 생각보다 자주 전하지 못합니다.

부모님의 취미는 무엇인지,  
힘든 날에는 어떻게 버텼는지,  
마지막으로 사랑한다고 말한 것은 언제인지.

알고 있을 것 같지만 막상 답하기 어려운 질문들은  
대부분 언젠가 물어보겠다고 미뤄둔 질문이기도 합니다.

> HALO는 부모님과의 관계를 한 번에 바꾸는 서비스가 아닙니다.  
> 작은 질문과 행동을 통해 관계를 천천히 이어가는 서비스입니다.

---

## About HALO

부모님께 잘하고 싶은 마음은 있지만,  
어떤 말부터 꺼내야 할지 몰라 멈칫한 적이 있나요?

평소 하지 않던 질문은 어색하고,  
선물은 한 번의 이벤트로 끝나며,  
평범한 일상의 순간들은 기록되지 않은 채 지나갑니다.

HALO는 이러한 관계의 장벽을 낮추기 위해  
사용자에게 세 가지 경험을 제공합니다.

| Problem | HALO Experience |
| --- | --- |
| 대화를 시작할 계기가 부족함 | 자연스럽게 말을 꺼낼 수 있는 질문과 행동 |
| 선물과 이벤트가 일회성으로 끝남 | 하루 한 장씩 이어지는 관계 경험 |
| 평범한 순간이 기록되지 않음 | 사진, 감정, 이야기로 남는 스토리북 |

---

## Core Concept

HALO의 핵심은 **스토리북 구조**입니다.

사용자는 자신의 관계와 상황에 맞는 테마를 선택하고,  
스토리북이 제안하는 질문과 행동을 따라가며  
부모님과의 순간을 한 페이지씩 채워갑니다.

사진, 장면카드, 감정과 기록이 쌓이면  
부모님과 나만의 한 권의 이야기가 완성됩니다.

| Structure | Description |
| --- | --- |
| **Storybook** | 부모님과의 관계를 담은 하나의 테마 |
| **Chapter** | 하루에 하나씩 수행하는 기록 단위 |
| **Mission** | 대화, 행동, 관찰을 이끄는 작은 제안 |
| **Record** | 사진 또는 장면카드, 감정과 이야기 |
| **Completion** | 10개의 장을 채워 완성한 한 권의 이야기 |

---

## How HALO Works

| Step | Experience |
| :---: | --- |
| **01** | 소셜 로그인 후 관계 정보를 입력합니다. |
| **02** | 현재 관계와 원하는 방향을 온보딩에서 선택합니다. |
| **03** | 나에게 맞는 스토리북 테마를 추천받습니다. |
| **04** | 질문과 행동을 따라 하루 한 장씩 기록합니다. |
| **05** | 10개의 장을 채워 한 권의 스토리북을 완성합니다. |
| **06** | 캘린더와 테마 전시관에서 쌓인 관계를 돌아봅니다. |

---

## 10 Storybook Themes

각 테마는 서로 다른 관계의 순간을 담은  
**10개의 장**으로 구성됩니다.

| No. | Theme | Description |
| :---: | --- | --- |
| **01** | **오래전 당신** | 부모님의 과거를 따라가며, 부모님을 한 사람의 삶을 지나온 사람으로 다시 바라봅니다. |
| **02** | **당신 사용설명서** | 부모님의 취향과 생활 방식, 좋아하는 것과 조심해야 할 것을 알아갑니다. |
| **03** | **가족의 온도** | 말없이 오간 배려와 걱정, 위로와 웃음 속에 남은 가족의 온도를 발견합니다. |
| **04** | **취향이 닿는 날** | 음식, 음악, 콘텐츠와 장소를 함께 경험하며 서로 맞닿는 취향을 찾아갑니다. |
| **05** | **나란히 걷는 날** | 집 앞 산책부터 조금 먼 외출까지 부모님의 속도에 맞춰 같은 시간을 보냅니다. |
| **06** | **오늘은 내가 먼저** | 받기만 했던 돌봄을 이번에는 질문과 연락, 작은 행동으로 먼저 건넵니다. |
| **07** | **생신까지 열 장** | 생신 당일뿐 아니라 준비하는 열흘의 과정을 기록하며 마음을 완성합니다. |
| **08** | **한 장의 가족사진** | 평범한 일상부터 특별한 순간까지 가족의 모습을 한 장씩 사진으로 남깁니다. |
| **09** | **손을 내미는 연습** | 부끄럽고 어색해서 미뤄왔던 다정한 표현을 작은 단계부터 연습합니다. |
| **10** | **당신의 1호 팬** | 부모님을 챙겨야 할 사람이 아닌, 내가 응원하고 좋아하는 한 사람으로 바라봅니다. |

## Main Features

### Personalized Onboarding

사용자마다 부모님과의 관계는 다릅니다.

HALO는 온보딩을 통해  
부모님의 성향, 현재 관계 상태, 원하는 관계 방향과  
부담을 느끼는 주제를 파악합니다.

이를 바탕으로 사용자가 부담 없이 시작할 수 있는  
스토리북 테마를 추천합니다.

---

### Daily Chapter

각 장은 단순한 질문지가 아니라  
실제 관계의 변화로 이어질 수 있는 작은 경험으로 구성됩니다.

- 부모님께 자연스럽게 건넬 질문
- 함께하거나 먼저 실천하는 행동
- 사진 또는 장면카드
- 그날의 감정 태그
- 한 페이지에 남기는 이야기

갑자기 큰 표현을 요구하지 않고,  
한 장씩 따라가다 보면 관계가 쌓이도록 설계합니다.

---

### Storybook

사용자는 마치 한 권의 책을 읽듯  
스토리북이 제안하는 흐름을 따라갑니다.

하루 한 장씩 채워진 사진과 기록, 감정은  
단순한 미션 결과가 아니라  
부모님께 다가가려 했던 과정이 담긴 이야기가 됩니다.

---

### Calendar

스토리북의 장을 완료한 날짜를 달력에서 확인하고,  
해당 날짜에 남긴 사진과 감정, 기록을 다시 돌아볼 수 있습니다.

부모님 생신, 어버이날과 사용자 지정 기념일도 함께 관리하여  
관계를 이어갈 수 있는 계기를 놓치지 않도록 돕습니다.

---

### Theme Exhibition

스토리북을 완성하면  
해당 테마를 상징하는 캐릭터를 수집할 수 있습니다.

완성한 스토리북과 캐릭터를 전시관에서 감상하며  
지금까지 부모님과 함께 만든 이야기를 돌아봅니다.

---

### My Page

사용자의 관계 정보와 서비스 설정을 관리합니다.

- 관계 대상
- 부모님 성향
- 현재 관계 상태
- 원하는 관계 방향
- 기념일 관리
- 정기 알림 설정
- 계정 및 서비스 설정

---

## What HALO Wants to Create

관계는 거창한 이벤트보다  
작은 계기로 달라질 수 있다고 생각합니다.

한 번의 비싼 선물보다 먼저 건넨 안부가,  
특별한 여행보다 함께 걸었던 동네 한 바퀴가,  
완벽한 대화보다 어색하게 꺼낸 한마디가  
더 오래 기억될 수 있습니다.

HALO는 부모님과의 관계를 대신 해결하지 않습니다.

대신 사용자가 부모님께 다가갈 수 있는  
**작은 시작 버튼**이 되고자 합니다.
