## About HALO

부모님께 잘하고 싶은 마음은 있지만,  
막상 어떤 말을 꺼내야 할지 몰라 미뤄본 적이 있나요?

**HALO**는 부모님과의 관계를 한 번에 바꾸는 서비스가 아닙니다.  
대신 매일 하나의 질문, 작은 행동, 짧은 기록을 통해  
부모님과의 관계를 천천히 이어가도록 돕습니다.

사용자는 다양한 **스토리북 테마**를 선택하고,  
하루에 한 장씩 부모님과의 이야기를 채워가며  
관계를 하나의 기록으로 완성할 수 있습니다.

---

## Core Concept

HALO의 핵심은 **스토리북 구조**입니다.

각 스토리북은 하나의 관계 주제를 담고 있으며,  
사용자는 10개의 장을 따라가며 부모님과의 대화와 행동을 기록합니다.

| Structure | Description |
| --- | --- |
| Storybook | 부모님과의 관계를 담은 하나의 테마 |
| Chapter | 하루에 하나씩 수행하는 기록 단위 |
| Mission | 대화, 행동, 관찰을 유도하는 작은 미션 |
| Record | 사진 또는 장면카드, 답변, 감정 기록 |
| Completion | 10장을 채우면 하나의 이야기 완성 |

## Main Features

### Storybook

부모님의 과거, 취향, 가족의 기억, 함께 보내는 시간 등  
다양한 주제의 스토리북을 제공합니다.

사용자는 원하는 테마를 선택해  
부모님과의 이야기를 하루 한 장씩 채워갈 수 있습니다.

### Chapter Mission

각 장은 단순한 질문이 아니라  
실제로 대화하고 행동할 수 있도록 구성됩니다.

- 부모님께 물어볼 질문
- 함께 해볼 작은 행동
- 기록으로 남길 답변
- 사진 또는 장면카드
- 감정 태그

### Theme Exhibition

완성한 스토리북은 테마 전시관에서 다시 감상할 수 있습니다.

기록을 단순히 보관하는 것이 아니라,  
부모님과 함께 만든 이야기를 포토카드처럼 가볍게 돌아볼 수 있습니다.

### Calendar

스토리북을 수행한 날짜와  
부모님 생신, 어버이날, 사용자 지정 기념일을 함께 확인할 수 있습니다.

사용자는 캘린더를 통해  
부모님과의 관계를 이어온 흔적을 한눈에 볼 수 있습니다.

### My Page

사용자의 관계 정보와 설정을 확인할 수 있습니다.

- 관계 대상
- 부모님 성향 태그
- 현재 관계 상태
- 원하는 관계 방향
- 기념일 관리
- 알림 설정
